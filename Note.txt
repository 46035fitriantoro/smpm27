Berikut daftar yang harus diinstall di PC baru:

1. Flutter SDK — flutter 3.44.6 stable

Download: https://flutter.dev
Extract ke C:\flutter, lalu tambahkan C:\flutter\bin ke PATH
2. Android Studio (untuk Android SDK & tools)

Android SDK Platform: 34, 35, 36
Android Build Tools: 35.0.0, 36.1.0, 37.0.0
Android SDK Location: C:\Users\<user>\AppData\Local\Android\sdk
3. Java (JDK) — JDK 21

Atur JAVA_HOME dan tambahkan bin/ ke PATH
4. Setelah Flutter terinstall, jalankan:

flutter doctor
Pastikan semua checklist hijau.

5. Clone project & build:

git clone <repo>
cd <project>
flutter pub get
flutter build apk --release
Catatan penting: Gradle versi 8.14, Android Gradle Plugin 8.11.1, Kotlin 2.2.20, dan Java 17 target — semua sudah diatur di file project (gradle-wrapper.properties, settings.gradle.kts, build.gradle.kts), jadi tidak perlu install manual. Flutter akan download Gradle wrapper otomatis saat pertama build.



flutter clean
flutter pub get
flutter build apk --release --no-daemon


Ringkasan security:

Fitur	Implementasi
Anti Screenshot/Screen Recording	FlutterWindowManager.FLAG_SECURE + permission READ_FRAME_BUFFER
Anti Copy Paste	JavaScript block: copy, cut, paste, contextmenu, keyboard shortcuts (Ctrl+C/V/X/U/S), F12, PrintScreen
Anti Text Selection	Disable selectstart, mousedown di non-input elements
Anti Inspect Element	Override console.* methods, block DevTools
Lock Home/Back	PopScope + dialog konfirmasi keluar
Lock Task Mode	android:lockTaskMode="if_whitelisted" (bisa di-pin ke screen via Settings > Security)
Anti Multi-Window	android:resizeableActivity="false"
Anti App Switch	WidgetsBindingObserver detect lifecycle + warning overlay merah + counter pelanggaran + report ke server
Screen Wake Lock	wakelock_plus — layar tetap menyala selama ujian
Immersive Mode	SystemUiMode.immersiveSticky — sembunyikan status bar & nav bar
Orientation Lock	Portrait only (tidak bisa landscape)
Anti Zoom	supportZoom: false, builtInZoomControls: false
Tambahan untuk admin:

Lock Task Mode bisa diaktifkan via Settings > Security > Screen Pinning di HP siswa
Pelanggaran app switch dihitung dan bisa di-report ke server via JavaScript window.onAppSwitch(count)
